# Off-site and local SEO checklist (done by hand)

Code cannot do these. Tick each once done and update the build tracker (SEO11, SEO14, SEO15).

## Search Console and analytics (SEO15, SEO09, SEO17)
- [ ] Verify the domain `oyun.co.in` in Google Search Console with the DNS record (covers every subdomain). Also set `GOOGLE_SITE_VERIFICATION` if you prefer the meta tag.
- [ ] Submit `https://www.oyun.co.in/sitemap.xml`. After launch confirm every URL returns 200.
- [ ] Bing Webmaster Tools: import the site from Search Console, set `BING_SITE_VERIFICATION` if asked.
- [ ] Set `NEXT_PUBLIC_GA_ID`. Events: search, venue view, hold, paid booking.
- [ ] After deploy, run URL Inspection on `/`, `/arenas`, one sport, one area and one turf page.
- [ ] Weekly: indexed pages, queries, Core Web Vitals, security reports.

## Google Business Profile and listings (SEO11)
- [ ] Create and verify a Google Business Profile for OYUN (category: Sports Club / Booking Service, area: Mangalore).
- [ ] Each partner turf claims its own profile and adds the OYUN page as website and booking link.
- [ ] Same name, address and phone everywhere (NAP). Keep one spreadsheet.
- [ ] Listings: Justdial, Sulekha, Bing Places, Apple Maps, MapmyIndia, Facebook, Instagram, LinkedIn, YouTube.
- [ ] Ask real players for Google reviews after check-in. Never buy or fake reviews.
- [ ] Track calls, direction requests and bookings from local search.

## Links and reputation (SEO14)
- [ ] Partner turfs link to their OYUN page (bio, WhatsApp Business, badge).
- [ ] Colleges and clubs: NITK, St Aloysius, SDM, Srinivas, local football and cricket clubs share OYUN.
- [ ] Local press and sports blogs: launch press release with real numbers.
- [ ] Monthly Mangalore turf price index (data piece) pitched to local media.
- [ ] Use `rel="sponsored"` or `nofollow` on paid or exchanged links. No link schemes.

## AI answers
- [ ] Every month ask ChatGPT, Perplexity and Google AI: "best turf booking in Mangalore", "box cricket Mangalore", "pickleball courts in Mangalore". Record whether OYUN is named; fix the page that should answer.
